# صور الشهادات

ضع صور الشهادات هنا بالأسماء التالية (jpg أو png أو webp)، ثم شغّل `node brochure/build.js`:

| الملف | الشهادة |
|---|---|
| cert-01 | السجل التجاري |
| cert-02 | ترخيص الهيئة السعودية للمهندسين |
| cert-03 | شهادة تسجيل مكتب هندسي — أمانة جدة |
| cert-04 | رخصة نشاط تجاري — بلدي |
| cert-05 | ترخيص الدفاع المدني |
| cert-06 | ترخيص مزاولة نشاط — سلامة |
| cert-07 | شهادة ضريبة القيمة المضافة |
| cert-08 … cert-10 | شهادات / اعتمادات إضافية |

أي خانة ليس لها صورة تبقى إطارًا فارغًا في البروشور.
