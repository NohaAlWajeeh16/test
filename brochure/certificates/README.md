# صور الشهادات

| الملف | الشهادة |
|---|---|
| cert-01 | ترخيص الهيئة السعودية للمهندسين — ترخيص نهائي |
| cert-02 | ترخيص مزاولة نشاط — سلامة (الدفاع المدني) |
| cert-03 | رخصة نشاط تجاري — بلدي (أمانة جدة) |
| cert-04 | ترخيص الدفاع المدني — سلامة |
| cert-05 | موافقة الهيئة العليا للأمن الصناعي |
| cert-06 | خطاب الهيئة العليا للأمن الصناعي |
| cert-07 | رخصة بناء — عمارة سكنية (البيانات الخاصة مموّهة) |
| cert-08 | رخصة بناء — فيلا سكنية (البيانات الخاصة مموّهة) |

لتغيير شهادة: استبدل الملف بنفس الاسم ثم شغّل `node brochure/build.js`.
